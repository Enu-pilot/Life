## 1. 目的

自分自身の将来設計のために、人生の選択（就職・転職・結婚・出産・住宅購入・退職など）が将来の収支・資産・生活設計に与える影響を**比較・検証**できる Web アプリ「LifePlan」を開発する。

家計簿（過去の記録）や資産管理（現在の残高把握）ではなく、**将来に向けた「もしも」の比較**が主目的である。

## 2. 利用者と利用形態

| 項目 | 内容 |
|---|---|
| 主な利用者 | 開発者本人（1名）。家族の情報（配偶者・子）を含めて計画する |
| 利用端末 | PC ブラウザ（主）。スマートフォンは閲覧・軽微な編集ができれば可（初期版は PC 最適化優先） |
| アカウント | 不要（初期版） |
| ネットワーク | 初回読み込み後はオフラインでも計算・閲覧可能であることが望ましい |
| データの所在 | ブラウザ内（IndexedDB）。外部サーバーへ個人データを送信しない |

## 3. 基本方針（制約）

1. **ローカル完結**: 個人データ（収入・資産・家族構成など）を外部サーバーへ送信しない。解析ツール・外部フォント・CDN からの実行時読み込みも原則使わない。
2. **計算ロジックと UI の分離**: 計算エンジンは純粋関数（入力 → 出力）として UI・保存層から独立させ、単体でテスト可能にする。
3. **前提の明示**: 金額単位、期間、税・社会保険の扱い、利回り、物価上昇率など計算前提を画面上で常に確認できるようにする。
4. **予測であることの明示**: シミュレーション結果は前提に基づく予測値であり、将来を保証しない旨を画面・エクスポート物に明示する。
5. **拡張性**: イベント種別・税計算・確率的シミュレーションなどを後から追加できるデータモデル・計算構造にする。
6. **未確定事項は決め打ちしない**: 重要な判断は [open-questions.md](./open-questions.md) で管理し、承認後に確定する。

## 4. 用語

| 用語 | 定義 |
|---|---|
| シナリオ | 1つの人生計画（世帯・前提・収支・資産・イベントの一式）。比較の単位 |
| 世帯メンバー | 本人・配偶者・子。生年月を持ち、年齢計算の基準になる |
| 口座（アカウント） | 資産または負債の残高を持つ入れ物。現金・預金・投資・不動産・車両・ローン等 |
| 収支項目 | 定常的に発生する収入・支出（給与、生活費、家賃など）。期間と頻度を持つ |
| 人生イベント | 特定時点に発生し、一時的な収支や新たな収支項目・口座を生成する出来事（住宅購入、出産など） |
| 計算前提（Assumptions） | 物価上昇率・運用利回り・シミュレーション期間など、シナリオ全体に効くパラメータ |
| 資金不足 | 現金（流動資金）口座の残高が 0 未満になる状態 |
| 純資産 | 資産合計 − 負債合計 |

## 6. 初期リリース（v1.0）のスコープ

**含む**: 上記 P1 の全機能。すなわち

1. プロフィール（本人・配偶者・子）と計算前提の入力
2. 収入・支出・資産・負債・積立の入力（収入は手取りベース）
3. 人生イベント（汎用、就職/転職、退職、結婚、出産、教育費、賃貸、住宅購入＋ローン、自動車、年金、老後生活費）
4. 月次計算・年次集計による資産推移の表・グラフ、資金不足警告、年次明細
5. シナリオの作成・複製・比較（最大 4）
6. 自動保存、JSON バックアップ/復元、スキーマバージョン管理
7. 計算前提・免責表示、サンプルデータ

**含まない**: 税・社会保険の詳細計算、運用益課税の自動計算、モンテカルロ、クラウド同期、アカウント、暗号化、PWA。

## 7. 非機能要件

| 区分 | 要件 |
|---|---|
| 性能 | 100 年（1,200 か月）× イベント 50 件のシナリオ 1 本の再計算が 50ms 以内（一般的な PC）。入力変更から画面反映まで体感 200ms 以内 |
| 正確性 | 計算エンジンは円単位整数で収支を確定し、資産の恒等式（期首残高 + 流入 − 流出 = 期末残高）が全月で成立すること |
| 再現性 | 同一入力からは常に同一結果（乱数・現在時刻に依存しない。開始年月は入力値として持つ） |
| プライバシー | 個人データを外部送信しない。外部通信は静的アセット配信のみ（自前ホスティング時） |
| データ保全 | スキーマ変更時はマイグレーションで既存データを引き継ぐ。インポート失敗時に既存データを壊さない |
| 可用性 | ブラウザのストレージ消去でデータが消えうることを利用者に明示し、エクスポートを促す |
| アクセシビリティ | キーボード操作可能、フォームラベル必須、グラフは表でも同じ情報を確認できる |
| ブラウザ | 最新版の Chrome / Edge / Firefox / Safari |
| 保守性 | TypeScript strict、計算エンジンのテストカバレッジ（行）90% 以上 |

## 8. 免責表示（文言案）

> 本アプリの計算結果は、入力された条件と計算前提に基づく試算（予測値）であり、将来の収入・支出・資産額を保証するものではありません。税金・社会保険・年金等の制度は簡易的に扱っており、実際の金額とは異なる場合があります。重要な意思決定にあたっては、専門家への相談や公的機関の情報をご確認ください。
