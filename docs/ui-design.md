# LifePlan UI・UX 設計書

- 文書状態: Phase 0 ドラフト（承認待ち）
- 最終更新: 2026-10-26

---

## 1. 設計方針

1. **入力 → 結果がすぐ見える**: どの編集画面でも右側（狭い画面では下部）に「ミニ資産推移グラフ」を常時表示し、変更の影響を即座に確認できる。
2. **前提を隠さない**: 画面ヘッダに主要前提（物価上昇率・運用利回り・手取り入力であること）をチップで常時表示。クリックで前提画面へ。
3. **予測であることを明示**: 結果を表示する画面のフッタに免責文言を表示。
4. **元に戻せる**: 削除は確認ダイアログ。イベントは削除ではなく「無効化」を推奨動線にする。
5. **金額入力の負担を減らす**: 万円単位入力の切替、カンマ区切り自動整形、月額⇔年額の換算表示。

## 2. 画面一覧と画面遷移

```
グローバルナビ（左サイドバー / スマホは下部タブ）
├─ ① ダッシュボード            #/
├─ ② プロフィール・前提条件     #/profile
├─ ③ 収入・支出・資産          #/finances   （タブ: 収入 / 支出 / 資産・負債 / 積立）
├─ ④ 人生イベント             #/events     → イベント編集 #/events/:id（ドロワー）
├─ ⑤ 資産推移                #/projection （タブ: グラフ / 年次表）→ 年次明細（ドロワー）
├─ ⑥ シナリオ                #/scenarios  → 比較 #/scenarios/compare?ids=a,b,c
├─ ⑦ データ管理               #/data       （エクスポート / インポート / 初期化）
└─ ⑧ 設定・計算前提            #/settings   （表示単位・計算前提一覧・免責・バージョン）

ヘッダ: [アプリ名] [シナリオ切替ドロップダウン ▼] [前提チップ] [保存状態: 保存済み✓]
```

- ヘッダのシナリオ切替は全画面共通。②〜⑤は「現在のシナリオ」を編集・表示する。
- 初回起動（データなし）は①が「はじめに」状態（§4）となり、②へ誘導。

## 3. 各画面の定義

### ① ダッシュボード

| 要素 | 内容 |
|---|---|
| サマリーカード | 現在の純資産 / 金融資産、65歳時点（年齢は設定可能）の純資産、最低現金残高と年齢、資金不足の有無 |
| 警告エリア | 資金不足（初回年齢・最大不足額）、検証警告（住居費の重複・期間外イベント等）。各警告から該当編集画面へリンク |
| 資産推移グラフ（縮小版） | ⑤への導線 |
| 直近のイベント | 今後 10 年のイベント一覧 |
| バックアップ状態 | 最終エクスポート日時。未実施なら推奨表示 |

### ② プロフィール・前提条件

| 入力項目 | 型・制約 | 既定値 |
|---|---|---|
| 本人: 呼び名 | 文字列 0〜20 | 「本人」 |
| 本人: 生年月 | YYYY-MM、1900-01〜開始年月 | 必須 |
| 配偶者: 有無・呼び名・生年月 | 同上 | なし |
| 子: 呼び名・生年月（追加/削除） | 同上（将来の生年月も可＝出産予定） | なし |
| シミュレーション開始年月 | YYYY-MM | 作成時の翌月 |
| 終了年齢（本人） | 60〜110 の整数 | 100 |
| 物価上昇率 | −5〜+15 %、小数2位 | 【要決定 Q-18】推奨 1.5% |
| 既定運用利回り（税引後） | −10〜+15 % | 【要決定 Q-18】推奨 3.0% |
| 資金不足時の自動取り崩し | ON/OFF | OFF |

### ③ 収入・支出・資産

- タブごとに一覧（表）＋「追加」ボタン。行クリックで編集ドロワー。
- **収入/支出の入力項目**: 名称、カテゴリ、対象者、金額、頻度（毎月 / 毎年◯月 / 指定月）、開始（年月・年齢）、終了（年月・年齢・なし）、上昇（なし / 物価連動 / 固定率）。
  - 一覧に「月額換算」「年額換算」列を表示。
  - 収入入力欄には「手取り額で入力してください」の注記を固定表示。
- **資産・負債**: 名称、種別、開始時点残高、利回り（投資・預金）、ローンの場合は金利・残期間・返済方式。
  - `cash`（生活口座）は1つ固定で削除不可。
- **積立**: 振替元（既定 cash）、振替先、月額、期間、上昇率。

### ④ 人生イベント

- **一覧**: 発生年月・年齢順のタイムライン形式。各行に種別アイコン、名称、発生時（年月・本人年齢）、主な金額、有効/無効トグル。
- **追加**: 「イベントを追加」→ 種別選択（カード形式: 結婚・出産・住宅購入・…・汎用）→ 種別ごとのフォーム（テンプレート既定値入り）。
- **編集フォーム共通項目**: 名称、発生時期（年月 / 年齢 / 学年）、有効、メモ、「この時点で終了する収支項目」（複数選択）。
- **種別別フォーム（主要）**:

| 種別 | 主な入力 |
|---|---|
| 住宅購入 | 物件価格、頭金、諸費用（物件価格の% or 円）、借入額（自動計算: 価格−頭金）、金利、期間、返済方式、固定資産税（年額）、修繕・管理費（月額）、評価額変動率、終了する家賃項目 |
| 自動車 | 車両価格、購入方法（現金/ローン）、買い替え周期（年）と回数 or 終了年齢、維持費（年額: 税・保険・車検・駐車場）、残価率 |
| 出産 | 子の呼び名・生年月（イベント月から自動）、出産費用（給付金差引後）、子育て費（月額、年齢区分）、教育コースのテンプレート適用有無 |
| 教育費 | 対象の子、各段階（幼・小・中・高・大）の公立/私立/なし、年額（テンプレート既定値・編集可）【既定値の出典は Q-19】 |
| 結婚 | 配偶者の生年月、結婚費用、配偶者の収入（収入項目を同時作成）、生活費の変化額 |
| 就職・転職 | 終了する給与項目、新しい給与（月額・賞与・上昇率） |
| 退職 | 終了する給与項目、退職金（手取り）、受取月 |
| 年金 | 対象者、受給開始年齢、年額（現在価値・手取り）、物価スライド率 |

- 保存前にイベントのプレビュー（「この変更で 65 歳時点の純資産が −1,234 万円」）を表示。

### ⑤ 資産推移

- **グラフタブ**:
  - 主グラフ: 積み上げ面（現金・預金・投資・不動産・車両）＋負債（負方向）＋純資産の線。X 軸は年（本人年齢併記）。
  - イベントマーカー（縦の参照線 + アイコン、ホバーで名称）。
  - 資金不足期間を赤背景で強調。
  - 副グラフ: 年間収入/支出の棒 + 年間収支の線。
  - 切替: 純資産 / 金融資産のみ、名目 / 実質（P2）。
- **年次表タブ**: 年、各メンバー年齢、収入、支出、収支、ローン元本、運用損益、金融資産、実物資産、負債、純資産。資金不足の行は強調。列の表示切替。
- **年次明細ドロワー**: 行クリックで、その年の仕訳をカテゴリ別・出所別（項目名 / イベント名）に表示。
- グラフと同じ情報は必ず表でも確認できる（アクセシビリティ）。

### ⑥ シナリオ

- **一覧**: カード（名称、説明、更新日時、65歳時純資産、資金不足有無のミニ指標）。操作: 開く / 複製 / 名称変更 / 削除 / 比較に追加（チェック）。
- **作成**: 「空から作成」「現在のシナリオを複製」「サンプルから作成」。
- **比較画面**（2〜4 件）:
  - 純資産推移の重ね合わせ線グラフ（シナリオごとに色・線種を変える）。
  - 指標比較表: 指定年齢時点の純資産・金融資産、最低現金残高（年齢）、資金不足（初回年齢・最大額）、生涯収入・支出、ローン完済年齢。最良値を強調。
  - 比較対象の前提条件の一覧（物価上昇率・利回り・開始年月が異なる場合は警告: 「前提が異なるため単純比較できません」）。
  - 差分表示（どの項目・イベントが違うか）は P2。

### ⑦ データ管理

- エクスポート: ボタン1つ。最終エクスポート日時を表示。
- インポート: ファイル選択 → 検証結果とプレビュー（シナリオ数・名称・保存日時・スキーマ版）→「現在のデータを置き換える」確認（現データは自動退避される旨を明記）。
- 自動退避の世代一覧と復元。
- 全データ削除: 確認文字列入力（「削除」と入力）による二重確認。
- 保存場所の説明: 「データはこのブラウザ内にのみ保存されます。ブラウザのデータ消去や端末変更で失われるため、定期的にエクスポートしてください。」

### ⑧ 設定・計算前提

- 表示単位（円/万円）。
- **計算前提の一覧（読み取り）**: 月次計算、年次は暦年集計、手取り入力、税・社保は計算しない、運用益は税引後利回り、ローン利息切り捨て、資金不足の扱い、年齢の数え方、学齢規則など calculation-spec の要点を平文で表示。
- 免責事項、アプリ版・計算エンジン版・スキーマ版。

## 4. 空データ時の表示

| 画面 | 表示 |
|---|---|
| ①（初回） | 「はじめに」カード: ① プロフィールを入力 → ② 収入・支出を入力 → ③ イベントを追加。並べて「サンプルデータで試す」ボタン |
| ③ 各タブ | 「まだ収入が登録されていません」＋追加ボタン＋入力例（例: 給与 手取り月 30 万円） |
| ④ | 「イベントがありません」＋主要イベントのカード（結婚・出産・住宅購入…） |
| ⑤ | 生年月未入力なら「プロフィールを入力すると推移を表示します」。入力済みで収支ゼロならグラフは表示（全期間 0）し、入力を促す |
| ⑥ 比較 | シナリオが1つだけなら「複製して条件を変えると比較できます」＋複製ボタン |

## 5. バリデーションとエラー表示

| 種類 | 表示方法 |
|---|---|
| フィールド単位エラー（必須・範囲・形式） | 入力欄直下に赤文字。フォーカスアウト時と保存時に検証。保存ボタンはエラーがあれば押下時にエラー箇所へスクロール |
| フォーム横断エラー（開始 > 終了、頭金 > 物件価格） | フォーム上部にまとめて表示＋該当欄を強調 |
| シナリオ全体の警告（エンジン検証 calculation-spec §14） | ダッシュボード警告エリア＋該当画面上部の黄色バナー。警告があっても計算・保存は可能 |
| シナリオのエラー（参照切れ等で計算不能） | グラフ領域に「計算できません: 理由」＋修正画面へのリンク。入力内容は保存される |
| 保存失敗（容量不足・プライベートモード等） | ヘッダの保存状態を赤「保存できません」に変え、エクスポートを促すダイアログ |
| インポート失敗 | ダイアログで段階（ファイル形式 / アプリ識別 / バージョン / 項目検証）と該当フィールドパスを表示。既存データは変更されない旨を明記 |

入力値の正規化: 全角数字・カンマ・「万」表記（例: `30万`）を受け付け、内部で円整数に変換する。

## 6. 主要操作フロー（E2E テスト対象）

1. 初回起動 → プロフィール入力 → 収入・支出入力 → ダッシュボードに推移表示
2. 住宅購入イベント追加 → 家賃終了指定 → グラフにローン負債・不動産が出現、家賃が購入月以降消える
3. シナリオ複製 → 複製側で利回り変更 → 比較画面で2本の線と指標差
4. エクスポート → 全削除 → インポート → 元と同じ結果
5. イベント無効化 → 結果が無効化前と異なり、再有効化で元に戻る

## 7. レスポンシブ・アクセシビリティ

- ブレークポイント: 1024px 以上で2カラム（編集 + ミニグラフ）、未満で1カラム。
- すべての操作をキーボードで実行可能。フォーム要素に `<label>` 必須。色だけで状態を表さない（資金不足は色＋アイコン＋文言）。
- グラフ配色は色覚多様性に配慮したパレットを使用。
