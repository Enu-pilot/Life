# LifePlan 操作説明書

- 対象バージョン: 1.0.0（計算エンジン 1.0.0／データ形式 v2）
- 最終更新: 2026-10-26

> 本アプリの計算結果は、入力された条件と計算前提に基づく試算（予測値）であり、将来の収入・支出・資産額を保証するものではありません。税金・社会保険・年金等の制度は簡易的に扱っており、実際の金額とは異なる場合があります。重要な意思決定にあたっては、専門家への相談や公的機関の情報をご確認ください。

## 1. 起動方法

必要なもの: Node.js 22 以上（`node -v` で確認）、最新の Chrome / Edge / Firefox / Safari。

```bash
npm install          # 初回のみ
npm run build        # 本番用にビルド
npm run preview      # http://localhost:4173 で起動（ブラウザで開く）
```

開発中は `npm run dev`（http://localhost:5173）でも起動できます。

- 起動後はインターネットに接続していなくても動作します。外部への通信は行いません。
- **データは開いた URL（例: `http://localhost:4173`）ごとにブラウザ内に保存されます。** ポート番号やブラウザを変えると別の保存領域になるため、いつも同じ URL で開いてください。移す場合はエクスポート → インポートを使います。

## 2. 基本の流れ

1. **プロフィール・前提**: 本人の生年月を登録します（必須）。配偶者・子、計算期間（開始年月・終了年齢）、物価上昇率、運用利回りの初期値を設定します。
2. **収入・支出・資産**:
   - 収入は**手取り額**で入力します（額面で入力して手取り率で簡易推計することもできます）。
   - 支出は「物価上昇率に連動」を選ぶと、毎年 1 月に物価上昇率だけ増えます。
   - 資産・負債には開始時点の残高を入力します。生活口座（現金・普通預金）はすべての入出金の口座で、世帯で 1 つです。
   - 積立（生活口座 → 投資）は支出ではなく口座間の振替として扱います。
3. **人生イベント**: 結婚・出産・教育費・賃貸・住宅購入・自動車・転職・退職・年金などを追加します。
   - 引っ越し・住宅購入・転職では、「この時点で終了する収支」で前の家賃や給与を選んでください（選ばないと重複して計上され、警告が出ます）。
   - 編集画面の下に「この変更による差分」が表示されます。
   - 一時的に外して比べたいときは、削除ではなく「無効にする」を使います。
4. **資産推移**:
   - グラフで資産の内訳・純資産・収入と支出を確認します。年次表で数値を確認でき、行を選ぶとその年の明細（期首 → 期末の内訳、収支の出所）が表示されます。
   - 「実質値」に切り替えると、物価上昇を割り引いた購買力の目安を表示します。
   - 「楽観・標準・悲観」で、利回りと物価を上下させた場合を比べられます（確率ではありません）。
   - 「CSV 出力」で年次表を保存できます。
5. **シナリオ**: 「表示中のシナリオを複製」してから条件を変えると、2〜4 件を比較画面で並べて比べられます（例: 住宅を買う／賃貸を続ける）。シナリオはそれぞれ独立しており、片方の編集はもう片方に影響しません。

初めて使う場合は、ダッシュボードの「サンプルデータで試す」で架空の世帯のシナリオを追加して、操作を確認できます。

## 3. 用語と表示の見方

| 用語 | 意味 |
|---|---|
| 収入・支出 | 世帯の外とのお金の出入り。ローン利息は支出に含み、ローン元本の返済・頭金・積立は含みません |
| 収支 | 収入 − 支出 |
| 生活口座 | すべての収入・支出の入出金先。マイナスになった月を「資金不足」として警告します |
| 金融資産 | 生活口座 + 預金 + 投資 |
| 実物資産 | 不動産・車両・その他資産の評価額（売却しない限り現金にはなりません） |
| 純資産 | 金融資産 + 実物資産 − 負債 |
| 資金不足 | 生活口座の残高が 0 未満の状態。前提条件で「自動取り崩し」を ON にすると預金 → 投資の順に補填します |

## 4. データの保存と保護

- 入力は自動で保存されます（右上に「保存済み ✓」と表示）。保存に失敗すると赤字で「保存できません」と表示されます。その場合は再試行するか、エクスポートしてください。
- **データ管理 → エクスポート** で、全シナリオ・前提条件・イベントを含む JSON ファイルを保存できます。**このファイルには個人情報が含まれます。** 取り扱いに注意してください。
- **インポート** の流れ:
  1. ファイルの形式・バージョン・必須項目・値の範囲を検証します。問題があれば理由（項目の場所）を表示して拒否し、現在のデータは変更しません。
  2. 確認画面（シナリオ名・エクスポート日時・改変の有無）を表示し、同意したときだけ置き換えます。
  3. 置き換える前のデータは「自動退避」に保存されます（最大 5 件）。
- 古い形式のデータ（v1）は、読み込み時に現在の形式（v2）へ自動で移行します。移行前のデータは自動退避に残ります。
- 保存データが壊れていて読み込めない場合は、削除せずに「生データの保存」か「退避して新規に開始」を選べます。
- ブラウザの閲覧履歴・サイトデータを消去すると、保存データも消えます。定期的にエクスポートしてください。

## 5. 計算前提（要約）

詳細は画面の「設定・計算前提」と `docs/calculation-spec.md` を参照してください。

- 月ごとに計算し、暦年で集計します。年齢は生年月による満年齢です（誕生月に加算）。
- 学齢は 4/2〜翌 4/1 生まれを同学年とします（4 月生まれは 4/2 以降生まれとみなす）。
- 運用は税引後の期待利回りで、月初の残高に月利を適用します。運用益への課税は計算しません。
- ローンの月利は年率 ÷ 12 です。返済額と利息は円未満を切り捨て、最終回で精算します。返済は毎月（ボーナス払いは未対応）。
- 年金の繰上げ・繰下げは、日本年金機構が示す増減率で計算します（2022 年 4 月施行。設定画面に出典を記載）。
- 教育費の既定値は文部科学省・日本政策金融公庫の調査結果（全国平均）です。上書きできます。

## 6. 対応していないこと

所得税・住民税・社会保険料の制度計算、運用益課税・NISA の区別、住宅ローン控除、繰上返済、不動産の売却・住み替え、在職老齢年金・加給年金、医療・介護の専用モデル、確率的シミュレーション（モンテカルロ）、クラウド同期・アカウント、エクスポートの暗号化、PWA・ダークモード。
